# Paylaşım öncesi güvenlik kontrolü

- [ ] Şirket kodu GitHub'da paylaşmaya izin verdi.
- [ ] Repository görünürlüğü PRIVATE.
- [ ] Gerçek APP_PIN, token, şifre, .env, D1 export data yok.
- [ ] Kaynak kodda şirket içi bilgi/patent/üretim sırrı olmadığını yetkili kişi kontrol etti.
- [ ] QR/Excel örnekleri gerçek veriler yerine anonimleştirilmiş verilerle oluşturuldu.
- [ ] Kaynakta PIN tarayıcının sessionStorage alanında tutuluyor: entegrasyonda merkezi kimlik doğrulama ile değiştirilmesi önerilir.
- [ ] Kodda hata mesajlarında veritabanı ayrıntısı ifşa riski incelendi.
- [ ] Ana sisteme geçmeden önce API yetki kontrolü ve eşzamanlı işlem testleri yapıldı.

**Private repository dahi şirketin erişim ve paylaşım politikalarına tabidir.**
